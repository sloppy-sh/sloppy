The judge's grades for that file go in the same row's last column: which judge, which model, and
the grades file it wrote.

What each run was sent is in its record's `sent`, and its stream in
`transcripts/<run_id>.jsonl.gz`, written as the run happens (`../README.md` § "What a run was sent,
and what it did"). A run that never started has neither.

`summary.json` and `figures/*.svg` are drawn from the results files here and their grades, never
edited by hand, and the published ones read the final test and the recommended-workflow batches
alone — `node bench.mjs export --seeds 30,31,32,41,42,43,44` — never the improvement-loop rounds
before them. Run it with a new batch's seed added after adding the batch or its grades, and commit
what it writes with them (`../README.md` § "The export").
